# Script-writing voice

When you (Claude) are writing the narration script for the video, follow these rules.

## Voice and tone

- **Conversational, not formal.** Write like a friend explaining something exciting, not a textbook.
- **Short sentences.** 8-15 words on average. Long sentences die on TikTok.
- **Hook in the first 2 seconds.** Open with a question, a bold claim, or a surprising fact. Never start with "Hi guys, today we're going to learn about..."
- **One idea per scene.** Each scene's narration should land one beat. If you're cramming two ideas in, split the scene.
- **End with payoff or CTA.** Last scene should either land an "aha" moment or invite the viewer to do something ("follow for more ocean facts").

## Pacing

- ~150 words per minute of video. Count carefully.
- 5s scene ≈ 12-15 words. 10s scene ≈ 25-30 words.
- Read your script out loud (in your head) at performance pace before finalizing. If it feels rushed, cut words.

## Structure templates by length

### 5-15s — single beat
Hook → punchline. Two scenes max.

### 30-60s — three-act mini
1. Hook (1 scene)
2. Setup / context (1-2 scenes)
3. Reveal / payoff (2-3 scenes)
4. Button (1 scene)

### 2-5 min — explainer arc
1. Cold open / hook
2. Why it matters
3. Main content (3-5 sub-beats, each 30-60s)
4. Summary
5. CTA

### 5-10 min — chapter format
Use 3-5 named chapters. Each chapter is a mini three-act. Add brief transitions ("but here's where it gets weird...").

## Anti-patterns

- ❌ "In this video, we will discuss..." (cut all meta-narration)
- ❌ "As you can see..." (the viewer can see)
- ❌ Three-syllable words where one-syllable works
- ❌ Repeating what the visual already shows
- ❌ Generic openings ("hey everyone", "what's up guys")

## Scene-narration coupling

The narration and the image should reinforce, not duplicate. If the visual shows an octopus waving, the narration shouldn't say "here's an octopus waving" — it should say "meet Otto, the smartest creature in the reef." The visual and the text are two channels carrying complementary information.
