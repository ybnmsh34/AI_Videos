# AI Video Creator (free-stack)

This skill gives Claude the ability to generate finished animated short videos end-to-end, using only free public services and local tools. No paid API keys are required.

## The principle

Video is just frames at a frame rate. We target **24fps**, so a 60-second video is **1440 frames**. We don't generate every frame from a model (impractical with free services and inconsistent visually). Instead:

- **~1 keyframe per scene** (every 4-8s) is generated by an image model
- **FFmpeg synthesizes the motion** between/within keyframes — zooms, pans, parallax, transitions — producing all 1440 frames at 24fps
- Optionally, **HuggingFace's free SVD** turns keyframes into real AI motion clips, when its free tier permits

The output is a true 24fps MP4 of the requested length, every frame present.

## When to use this skill

Trigger whenever the user asks for:
- "Make / create / generate a video / short / reel / TikTok / cartoon"
- "Animate this story / idea"
- "Turn this script into a video"

## Pipeline

```
user prompt
   │
   ▼
[1] Claude writes script.md
   │
   ▼
[2] Claude writes storyboard.json
   │
   ▼
[3] render.py:
     for each scene:
       a. image  ←  pollinations.ai  (free, no auth)
       b. clip   ←  ffmpeg Ken Burns / parallax motion  (or HF SVD if available)
       c. voice  ←  edge-tts        (free Microsoft neural voices)
     compose:
       concat clips + mix narration + burn captions
   │
   ▼
output/<slug>.mp4   (24fps, 9:16 or 16:9)
```

## Step-by-step instructions for Claude

### 1. Intake
Ask the user (use `AskUserQuestion` only if multiple things are unclear):
- **Topic / idea** (required)
- **Length** — 5 to 600 seconds. Default 30s.
- **Style** — `cartoon` (default), `whiteboard`, `anime`, `claymation`, `pixel-art`. Or `auto` to infer from topic.
- **Aspect ratio** — `9:16` (default) or `16:9`
- **Voice** — name a vibe (warm female, deep male, energetic kid, calm narrator). Skill maps to an edge-tts voice.

Pick a kebab-case slug (e.g., `octopus-tides`). Create `work/<slug>/`.

### 2. Write the script
Read `prompts/script-system.md` for tone rules. Write narration aiming at ~150 words per minute of video. Save to `work/<slug>/script.md`.

### 3. Build the storyboard
Read `references/storyboard-schema.md` for the exact JSON shape. Save to `work/<slug>/storyboard.json`.

Critical rules (re-stated):
- Sum of `scenes[].duration_s` must equal `meta.total_duration_s`
- Each scene's image_prompt should include the consistent style suffix (from `references/styles.md`)
- For character consistency across scenes, repeat the character description verbatim every time
- Motion prompts describe physical motion in 1 sentence ("slow zoom in, gentle tentacle wave")

### 4. Render
First-time setup (only needed once per environment):
```bash
bash .claude/skills/ai-video-creator/scripts/setup.sh
```

Then render:
```bash
python3 .claude/skills/ai-video-creator/scripts/render.py work/<slug>/storyboard.json
```

The renderer is idempotent — re-running skips assets that already exist. Delete a scene's files in `work/<slug>/scenes/` to force regeneration of that scene only.

It prints progress like:
```
[render] scene 01:
[render]   image (pollinations): A cheerful purple octopus...
[render]   clip (ffmpeg-kenburns): 5.0s @ 24fps
[render]   tts (edge-tts, en-US-AriaNeural): Meet Otto, an octopus who...
...
[render] DONE -> output/octopus-tides.mp4
```

### 5. Deliver
Print the output path to the user. Offer to:
- Regenerate a specific scene with a tweaked prompt (edit storyboard.json, delete that scene's files, re-run)
- Re-export in a different aspect ratio
- Try HF SVD motion mode (env: `USE_HF_SVD=1`) for real AI motion if Ken Burns feels too static

## Voice selection (edge-tts)

The skill maps friendly names → edge-tts voice IDs in `references/voice-presets.md`. Defaults:

| Vibe | Voice ID |
|---|---|
| Warm energetic female (default) | `en-US-AriaNeural` |
| Calm female narrator | `en-US-JennyNeural` |
| Friendly male | `en-US-GuyNeural` |
| Deep male documentary | `en-US-DavisNeural` |
| Playful character | `en-US-AnaNeural` |
| British female | `en-GB-SoniaNeural` |

List all voices: `edge-tts --list-voices`

## Optional upgrades

These are off by default; toggle via env var before running render.py:

| Env var | Effect |
|---|---|
| `USE_HF_SVD=1` | Use HuggingFace Stable Video Diffusion (free tier) for image-to-video motion. May rate-limit on long videos; renderer falls back to ffmpeg motion automatically. |
| `HF_TOKEN=hf_xxx` | Optional HF token to lift the anonymous rate limit |
| `MUSIC_FILE=/path/to/song.mp3` | Add background music, ducked under narration |
| `FPS=30` | Override default 24fps |

## What this skill DOES NOT need

- ❌ No Replicate / OpenAI / ElevenLabs / Runway / Pika keys
- ❌ No GPU
- ❌ No login anywhere (baseline pipeline is fully anonymous)

## What it DOES need (one-time)

- ✅ Python 3.10+
- ✅ `ffmpeg` in PATH
- ✅ `edge-tts` Python package (installed by `setup.sh`)
- ✅ Internet access (for pollinations.ai and edge-tts)

## Don't

- Don't claim a video is done before `render.py` has printed the final path and the MP4 exists on disk
- Don't commit `work/` or `output/` to git (`.gitignore` covers this)
- Don't try to generate images yourself — always go through the renderer
- Don't skip the storyboard step. Even a 5s video gets a 1-scene storyboard for reproducibility.
