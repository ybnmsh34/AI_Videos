# מעקב חשבוניות — עוסק פטור 🧾

אפליקציית **PWA** (אפליקציית ווב הניתנת להתקנה בנייד) לניהול חשבוניות, מעקב הכנסות/הוצאות
וסיווג אוטומטי של הוצאות מוכרות למס הכנסה — מותאמת לעוסק פטור בישראל.

כל הנתונים נשמרים **מקומית במכשיר שלך** (localStorage) — אין שרת, אין הרשמה, פרטיות מלאה.
עובדת גם ללא חיבור לאינטרנט.

## יכולות

- **רישום חשבוניות והוצאות** — הוספה, עריכה ומחיקה של תנועות הכנסה והוצאה עם תאריך, ספק/לקוח, סכום, מספר חשבונית והערות.
- **סיווג להוצאות מוכרות** — כל הוצאה משויכת לקטגוריה עם אחוז הכרה למס (למשל טלפון 50%, רכב 45%, שירותים מקצועיים 100%). האפליקציה מחשבת אוטומטית את הסכום המוכר. ניתן לערוך את אחוזי ההכרה בהגדרות ולדרוס אחוז לכל תנועה בנפרד.
- **דוחות וסיכומים** — סיכום שנתי של הכנסות, הוצאות, הוצאות מוכרות ורווח חייב במס משוער; פילוח לפי קטגוריה; וסיכום חודשי.
- **מעקב תקרת מחזור** — סרגל התקדמות מול תקרת המחזור השנתית של עוסק פטור, עם התראה בהתקרבות/חריגה.
- **ייצוא לאקסל (CSV)** וגיבוי/שחזור מלא (JSON).

## איך מריצים

זוהי אפליקציית ווב סטטית — אין תלות ואין צורך ב־build.

**מקומית:**
```bash
# מכל שרת HTTP סטטי, למשל:
python3 -m http.server 8080
# ואז לפתוח בדפדפן: http://localhost:8080
```

> הערה: כדי שה־Service Worker (עבודה אופליין) והתקנה למסך הבית יעבדו, יש להגיש את הקבצים דרך `http://` או `https://` ולא דרך `file://`.

**התקנה לנייד:** פותחים את הכתובת בדפדפן בנייד → תפריט → "הוסף למסך הבית" / "Install app". האפליקציה תיפתח כמו אפליקציה רגילה במסך מלא.

## מבנה הקבצים

| קובץ | תיאור |
|------|-------|
| `index.html` | מבנה האפליקציה |
| `styles.css` | עיצוב מותאם לנייד (RTL, מצב כהה) |
| `app.js` | כל הלוגיקה — מצב, חישובים, שמירה מקומית |
| `manifest.json` | הגדרות PWA |
| `sw.js` | Service Worker לעבודה אופליין |
| `icons/` | אייקוני האפליקציה |

## ⚠️ הבהרה

האפליקציה היא כלי עזר לניהול ומעקב בלבד ו**אינה מהווה ייעוץ מס**. אחוזי ההכרה וכללי ההוצאות
המוכרות משתנים מעת לעת ותלויים בנסיבות הספציפיות של העסק. יש לאמת כל נתון וכל סיווג
מול רואה חשבון או יועץ מס מוסמך לפני הגשת דוחות לרשויות.
